# SPORTIX — فروشگاه تجهیزات ورزشی (نسخه ۳)

فروشگاه فارسی (RTL)، مینیمال، با تم روشن/تیره و پنل مدیریت جدا. بدون بک‌اند و آماده‌ی GitHub Pages.

## ساختار
| فایل | کار |
|---|---|
| `index.html` `style.css` `script.js` | فروشگاه |
| `admin/` | پنل مدیریت (آدرس: `/admin`) |
| `data.js` | داده‌ی پیش‌فرض (محصولات، دسته‌ها، پک‌ها، تنظیمات) |
| `common.js` `base.css` | کدها و استایل مشترک |

## پنل مدیریت
آدرس سایت را باز کن و بعد از اسم سایت `/admin` را بنویس، مثلاً `https://USERNAME.github.io/sportix/admin/`

- نام کاربری: `admin`
- رمز: `sportix87`

امکانات: داشبورد، محصولات (آپلود چند عکس، توضیحات، مشخصات فنی، تخفیف، موجودی)، سفارش‌ها و وضعیت آن‌ها، دسته‌بندی‌ها، پک‌های ورزشی، ویرایش متن‌های صفحه‌ی اصلی، بکاپ و انتشار.

## انتشار روی GitHub Pages
1. یک Repository عمومی بساز (مثلاً `sportix`).
2. همه‌ی فایل‌ها را (نه خود پوشه‌ی ZIP) در ریشه آپلود کن، شامل پوشه‌ی `admin` و فایل `.nojekyll`.
3. Settings > Pages > Deploy from a branch > `main` / `(root)`.

## ⚠️ دو محدودیت مهم
1. **امنیت ورود:** چون سایت فقط فرانت‌اند است، ورود ادمین یک قفل ظاهری است. رمز به‌صورت هش در `common.js` است ولی هر کسی که کد را ببیند می‌تواند دور بزندش. برای امنیت واقعی بک‌اند لازم است (مثلاً Django). تا آن موقع اطلاعات حساس داخل پنل نگذار.
2. **تغییرات فقط در مرورگر خودت ذخیره می‌شود.** برای اینکه بازدیدکننده‌ها هم تغییرات را ببینند: پنل > «داده‌ها و انتشار» > «دانلود data.js» و آن را در GitHub جایگزین فایل قبلی کن. (عکس‌های آپلودی داخل همین فایل ذخیره می‌شوند؛ برای سایت واقعی بهتر است عکس‌ها را در پوشه‌ی `images/` بگذاری و لینکشان را در پنل بدهی.)

## عکس‌ها
عکس‌های پیش‌فرض بر اساس کلیدواژه از اینترنت لود می‌شوند (loremflickr) و ممکن است دقیقاً همان محصول نباشند. اگر لود نشوند، تصویر جایگزین نمایش داده می‌شود. برای هر محصول در پنل می‌توانی عکس خودت را آپلود کنی.

## تغییر رمز
پنل > محتوای سایت > «تغییر رمز ورود»؛ هش جدید را در `common.js` جایگزین کن.
